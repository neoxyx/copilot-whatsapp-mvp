# copilot-whatsapp-mvp

Servicio Node.js/Express para integrar un asistente de WhatsApp con Evolution API y OpenAI.

## Variables de entorno

- OPENAI_API_KEY
- EVOLUTION_API_URL
- EVOLUTION_API_KEY
- INNSTACE_NAME
- DATABASE_URL
- PORT

## Despliegue

Este proyecto está preparado para desplegarse en Vercel usando la configuración de vercel.json.
